# Design System - Yet Another Store for Apt

This document outlines the visual identity and styling guidelines for **Yet Another Store for Apt**.

## Color Palette

The design is built around a modern, premium Dark Theme featuring a deep store base color combined with a signature Red accent.

### Color Tokens

- **Store Base Color (Dark Gray)**:
  - Hex: `#212826`
  - HSL: `hsl(163, 10%, 14%)`
- **Accent Color (Red)**:
  - Hex: `#D32F2F`
  - HSL: `hsl(0, 63%, 50%)`
- **Subtle Highlight**:
  - Hex: `#D32F2F1A` (10% opacity)
- **Text Primary**:
  - Hex: `#F8F8F2`
- **Text Secondary**:
  - Hex: `#ACADAD`

## Visual Assets & Logo Concept

- **Base Structure**: Dark gray store icon outline or 3D block representing the storefront.
- **Accent Elements**: Highlights, borders, or light beams in **Red**.
- **Inside the Store**: Stacked package cubes representing the packages managed by Advanced Package Tool.
- **App Tag**: APT

## Typography

- **Headings**: Outfit or Inter (sans-serif)
- **Body Text**: Inter (sans-serif)
- **Monospace (for CLI output/commands)**: Fira Code or JetBrains Mono
